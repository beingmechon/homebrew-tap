# beingmechon/homebrew-tap

Homebrew formulae for my tools.

```sh
brew install beingmechon/tap/stackdeck
```

## stackdeck

Your projects folder, as a control panel: a board for starting, stopping,
branch-switching and log-watching your local dev services. Zero dependencies,
binds 127.0.0.1, never talks to the internet.

- Source: https://github.com/beingmechon/stackdeck
- Formula source of truth: `packaging/homebrew/stackdeck.rb` in that repo,
  copied here by its `scripts/brew-release.sh` on each release.
